# Visualização de Dados com Python

## Descrição

Projeto de análise e visualização de dados desenvolvido em Python, utilizando uma base de dados de vendas para realizar consultas, organização e representação gráfica das informações.

## Tecnologias

- Python
- SQLite
- Pandas
- Matplotlib
- Seaborn

## Conceitos aplicados

- Banco de dados SQLite
- Manipulação de dados com Pandas
- DataFrames
- Consultas SQL
- Análise de dados
- Visualização de dados
- Criação de gráficos

## Funcionamento

O projeto utiliza dados de vendas armazenados em um banco SQLite. Os dados são consultados e carregados em um DataFrame do Pandas para análise e organização.

A partir dos dados, são realizadas análises por categoria e geradas visualizações gráficas para facilitar a interpretação dos resultados.

## Objetivo

Aplicar conceitos de programação em Python, banco de dados e análise de dados na prática, utilizando ferramentas de manipulação e visualização de informações.
